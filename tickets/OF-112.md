# OF-112 · Correlation IDs on every request

| Type | Priority | Points | Labels |
|------|----------|--------|--------|
| Task | Medium | 2 | `observability`, `middleware` |

## Description
Support can't trace a customer's complaint through our logs. We need a correlation ID on every request.

## Acceptance Criteria
- [ ] If the request has `X-Correlation-Id`, reuse it, otherwise generate a new GUID
- [ ] Return it in the `X-Correlation-Id` response header
- [ ] Every log line written during the request includes `CorrelationId` (use `logger.BeginScope`)
- [ ] ProblemDetails error responses include it as an extension property `correlationId`
- [ ] Middleware registered in the right place in `Program.cs`. Explain why order matters.
