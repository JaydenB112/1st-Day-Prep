# OF-109 · Check and reserve stock when an order is placed

| Type | Priority | Points | Labels |
|------|----------|--------|--------|
| Story 📘 | High | 5 | `orders`, `inventory`, `concurrency` |

## User Story
**As** a customer, **I want** to be told immediately when something is out of stock **so that** I'm not charged for items that never ship.

## Acceptance Criteria
- [ ] Ordering an inactive product → 422 `Product 'Widget 13' is not available.`
- [ ] Ordering more than `StockQuantity` → 422 `Insufficient stock for 'Widget 07' (requested 1, available 0).`
- [ ] On success, each product's `StockQuantity` is decremented
- [ ] Order + stock changes save in **one** `SaveChangesAsync` (atomic)
- [ ] Cancelling a Pending/Paid order restores stock (coordinate with OF-105)
- [ ] Tests for each rule

## Stretch / discussion
Two requests buy the last unit at the same time. What happens? Research **optimistic concurrency** in EF Core (`[ConcurrencyCheck]` / `RowVersion`, `DbUpdateConcurrencyException`).
