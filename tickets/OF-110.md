# OF-110 · Search, filter and sort products

| Type | Priority | Points | Labels |
|------|----------|--------|--------|
| Story 📘 | Medium | 3 | `api`, `linq` |

## Acceptance Criteria
`GET /api/products` supports:
- [ ] `?search=widget 0`: case-insensitive name contains
- [ ] `?minPrice=10&maxPrice=20`
- [ ] `?inStock=true`
- [ ] `?sortBy=price|name&sortDir=asc|desc` (default: id asc)
- [ ] `?includeInactive=true` (default: inactive products are hidden)
- [ ] All filters compose with pagination, and `totalCount` reflects the *filtered* count
- [ ] Filtering happens **in SQL**, not in memory (check the EF SQL log in the console)
