# OF-116 · Secure write endpoints with JWT bearer auth

| Type | Priority | Points | Labels |
|------|----------|--------|--------|
| Story 📘 | High | 5 | `security`, `auth` |

## Acceptance Criteria
- [ ] All `GET` endpoints stay anonymous
- [ ] `POST`/`PUT`/`PATCH` require a valid JWT (401 without, 403 with wrong role)
- [ ] Product create/update requires role `admin`, order create requires any authenticated user
- [ ] Locally, mint tokens with `dotnet user-jwts create --role admin` (no identity server needed)
- [ ] The `.http` file is updated with an `Authorization: Bearer {{token}}` example
- [ ] No secrets committed. Config via `appsettings` / user-secrets

<details><summary>Hints</summary>

`Microsoft.AspNetCore.Authentication.JwtBearer`, `AddAuthentication().AddJwtBearer()`, `AddAuthorization()`,
`[Authorize(Roles = "admin")]`, `[AllowAnonymous]`. `UseAuthentication()` must come **before** `UseAuthorization()`.
In prod this would be Entra ID (Azure AD), Auth0, or Duende IdentityServer.
</details>
