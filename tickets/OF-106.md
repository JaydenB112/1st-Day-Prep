| Type | Priority | Points | Reporter | Labels |

| Bug 🐞 | Medium | 1 | On-call alert | `error-handling`, `alerts` |

## Description
PagerDuty fired overnight: spike of 500s on `GET /api/customers/{id}`. It turned out a partner was polling deleted IDs.
A missing resource is a client problem (4xx), not a server error, and shouldn't page anyone.

Logs show: `System.NullReferenceException: Object reference not set to an instance of an object.`
